# dj-library-cleaner

Lokales Tool, das eine DJ-Library für Pioneer-Player (XDJ-RX3, CDJ-2000NXS2, CDJ-3000) vorbereitet: Format-Standard, Bereinigung von Tags und Duplikaten, Hotcue-, Grid- und Tonart-Vorschläge. Die Ergebnisse gehen als rekordbox-XML zurück nach rekordbox.

BPM- und Tonart-Daten von [GetSongBPM](https://getsongbpm.com).
